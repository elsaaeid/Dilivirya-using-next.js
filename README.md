# Dilivirya Admin Dashboard

A modern, full-featured admin dashboard for e-commerce and business management. Built with Next.js and React, it provides inventory, marketing, client, and order management, with a responsive UI and analytics.

## Tech Stack & Tools Used
- **Next.js**: React framework for SSR, SSG, and routing
- **React**: UI library for building components
- **Redux**: State management for cart and global state
- **Chart.js**: Data visualization and analytics
- **Axios**: HTTP client for API requests
- **MongoDB/Mongoose**: Database and models (if backend connected)
- **CSS Modules**: Scoped, modular component styles
- **Vercel**: Deployment and hosting
- **Bootstrap**: Utility classes for layout and responsiveness
- **ESLint**: Linting and code quality
- **ToastContext**: Custom context for notifications

## Features
- Next.js (React) framework
- Modular component structure
- Responsive sidebar and navigation
- Inventory, marketing, and client management units
- Chart.js dashboard analytics
- Themed login/register pages
- Toast notifications
